Política de privacidad

Agente Work and Travel · Última actualización: 20 de octubre de 2026

Esta aplicación es un asistente personal de uso privado. La usa únicamente su autor, sobre sus propias cuentas. No hay registro de usuarios ni acceso de terceros.

Datos de Google a los que accede

  • Correo (gmail.readonly): lee el asunto, el remitente, la fecha y el cuerpo de los mensajes que coinciden con los temas configurados por el usuario, para detectar trámites con fecha límite. Es un permiso de solo lectura: la aplicación no puede enviar, responder, archivar, etiquetar ni borrar correo.
  • Calendario (calendar.app.created): crea calendarios propios y administra únicamente los eventos que ella misma creó en ellos. No lee ni modifica los demás calendarios del usuario.

Cómo se usan

El contenido de un mensaje se analiza para decidir si corresponde a un tema que el usuario pidió vigilar y, en ese caso, extraer qué hay que hacer y para cuándo. El resultado se le envía al propio usuario por Telegram, y si lo confirma, se crea un evento en un calendario de la aplicación.

Terceros

Para ese análisis, el texto del mensaje se envía a la API de Gemini de Google, que lo procesa y devuelve el resultado. La aplicación usa el nivel gratuito de esa API; según los Términos de servicio de la API de Gemini, en el nivel gratuito Google puede usar el contenido enviado y las respuestas generadas para mejorar y desarrollar sus productos y servicios, incluidos sus modelos. Las notificaciones se entregan a través de la API de Telegram. No se comparten datos con ningún otro tercero y no se venden.

Qué se guarda y por cuánto

En una base de datos privada del propio usuario se guardan los identificadores de los mensajes ya analizados (para no procesarlos dos veces), un resumen breve, y los eventos propuestos con su estado. No se almacena el cuerpo completo de los mensajes. Los datos viven mientras la aplicación esté en uso y se eliminan al borrarla.

Uso limitado

El uso que esta aplicación hace de la información recibida de las APIs de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Revocar el acceso

El usuario puede retirarle el permiso en cualquier momento desde la página de permisos de su cuenta de Google. Al hacerlo, la aplicación deja de tener acceso de inmediato.
